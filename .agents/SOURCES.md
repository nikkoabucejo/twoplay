Notes for this repo:
- There is no official Tailwind CSS or SvelteKit skill. Svelte, shadcn-svelte, and the `twoplay` skill cover that ground.
- Clerk's skills target React and other framework SDKs. twoplay uses vanilla `@clerk/clerk-js` + `@clerk/ui`
  (modals via `openSignIn`/`openUserProfile`) and `@clerk/backend` on the server. Use their
  appearance and theming guidance, and ignore the React hook flows.
- The `convex` router mentions other `convex-*` skills that aren't installed. Fetch one from the repo above if needed.
- Convex skills that say "push to a deployment" mean the dev deployment (`pnpm dev` / `convex dev`).
  Never run `convex deploy` without being asked, and `convex-deploy-guard` applies.
